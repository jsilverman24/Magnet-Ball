# Magnet Ball

Control the impossible.

Magnet Ball is a fast-paced arcade game inspired by one of the wildest shots ever, launched by Tyrese Haliburton in Game 1 of the Eastern Conference Finals. What looked like a miracle shot is now in your hands.

Guide the basketball mid-air, adjust its trajectory, and fight gravity itself to sink the shot.

---

## Gameplay

- Press **SPACE** to shoot the ball  
- Use **W A S D** to control the ball mid-air  
- Press **TAB** to pause the game  

Avoid going out of bounds, beat the shot clock, and rack up points by making shots.

---

## Features

- Real-time ball physics with gravity and velocity  
- Mid-air control system for dynamic gameplay  
- Shot clock pressure system  
- Scoring, streaks, and lives tracking  
- Sound effects and music for immersion

## Installation

1. Clone the repository:
```bash
git clone https://github.com/jsilverman24/Magnet-Ball.git
cd Magnet-Ball
```

2. Install requirements:
```bash
pip install -r requirements.txt
```

3. Run the game:
```bash
python main.py
```
